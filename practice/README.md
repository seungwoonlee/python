# Practice (연습 및 테스트)

파이썬의 다양한 라이브러리와 기본 기능을 자유롭게 테스트하고 연습한 결과물들이 포함되어 있습니다.

## 연습 분야 및 파일
* **CSV 처리**: `csv-test.py`, `csv-test.csv`, `csv-test2.csv` (데이터 분석 기초)
* **파일 입출력**: `file-test.py`, `test.txt`, `city.txt` (텍스트 파일 읽기/쓰기 실습)
* **알고리즘/기초**: `times-table.py` (구구단 출력 및 반복문 활용)

## 테스트 데이터
연습 과정에서 사용되는 샘플 텍스트 및 데이터 파일들이 함께 관리됩니다.
